# Description

This project is a sample Python app using [monero-python](https://github.com/everoddandeven/monero-python).

# Instruction
1. `follow instructions to install monero-python https://github.com/everoddandeven/monero-python`
2. `git clone https://github.com/everoddandeven/xmr-sample-python`
3. `cd xmr-sample-python`
4. `python3 src/main.py`
